# PISA 2009 閱讀分數多元線性迴歸

這是一個以 PISA 2009 資料為基礎的互動式多元線性迴歸分析網頁，用來探討學生背景、家庭條件與學校特徵和閱讀分數（`readingScore`）之間的線性關係。

## 線上使用

GitHub Repository：  
<https://github.com/Nina-Lin203/1102_multiple-linear-regression>

開啟 `index.html` 即可使用互動式分析頁面。網頁會自動讀取同一資料夾中的 `pisa2009train.csv`，不需要使用者上傳檔案。

## 專案檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 互動式迴歸分析網頁，包含 HTML、CSS 與 JavaScript |
| `pisa2009train.csv` | PISA 2009 訓練資料 |

## 資料處理

- 依變數為 `readingScore`。
- 刪除任一欄位含有 `NA` 的資料列。
- 將 `raceeth` 轉換為虛擬變數（one-hot encoding）。
- `raceeth=White` 設定為基準組，因此其他 raceeth 係數皆代表相對於 White 的差異。
- 目前使用的完整資料共有 2,414 筆。

## 分析功能

### 多元線性迴歸

使用普通最小平方法（OLS）估計迴歸係數，並顯示：

- R²
- 調整後 R²
- RMSE
- MAE
- 模型方程式
- 實際值與預測值散佈圖

### 特徵係數與統計檢定

特徵係數表包含：

- 原始迴歸係數
- 標準化係數 β
- t 值
- p 值
- 共線性 VIF

係數旁的顯著性標記如下：

- `*`：`p < 0.1`
- `**`：`p < 0.05`
- `***`：`p < 0.01`

此外，模型評估區會顯示整體 F 檢定，用來檢定所有斜率係數是否同時為 0。

### 特徵縮減

目前採用單次係數檢定進行特徵縮減：

1. 先估計完整模型。
2. 保留完整模型中 `p < 0.1` 的特徵。
3. 使用保留的特徵重新估計縮減模型。
4. 比較縮減前後的特徵數、R²、調整後 R²、RMSE、MAE 與整體 F 檢定。

### VIF 共線性分析

每個自變數都會以其他自變數進行輔助迴歸，並計算：

```text
VIF = 1 / (1 - R²)
```

一般判讀參考：

- `VIF < 5`：共線性通常可接受
- `5 ≤ VIF < 10`：需要注意
- `VIF ≥ 10`：可能有嚴重共線性

### 殘差明細表

殘差明細表顯示縮減模型保留的特徵，以及完整模型的：

- 實際 `readingScore`
- 預測值
- 殘差
- 誤差百分比

殘差計算方式：

```text
殘差 = 實際 readingScore - 預測值
```

## 目前模型結果

以目前資料與完整模型計算：

- R²：`0.3251`
- 調整後 R²：`0.3172`
- RMSE：`73.37`
- MAE：`58.41`
- 整體 F：`41.04`
- 整體 F 檢定 p 值：`0.0000`（實際值極小）

以上結果是以完整案例資料計算，載入資料或模型設定變更時，頁面會重新計算。

## 使用限制

- 本專案採用完整案例分析，含有 `NA` 的資料列會被排除，可能造成樣本選擇偏誤。
- 模型使用的是訓練資料，尚未切分獨立測試集。
- R²、p 值與係數只描述資料中的統計關聯，不代表因果關係。
- 正式預測或研究用途應進一步加入交叉驗證、測試集評估、殘差診斷與模型假設檢查。
